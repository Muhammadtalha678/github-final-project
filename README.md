# Simple Interest Calculator

A simple command-line tool written in Bash that calculates the simple interest earned on a principal amount over a specific time period at a given interest rate.

## Description
This project provides a simple utility to quickly determine simple interest calculations. It takes inputs directly from the user in the terminal and returns the computed total interest value.

## Input Fields
* **Principal Amount:** The initial sum of money invested or borrowed.
* **Rate of Interest:** The annual interest rate percentage.
* **Time Period:** The duration of the investment or loan in years.
